# Doorbell logo

A bell whose body is an arched doorway: the door a child walks through, and the bell that tells the parent.

| File | Use |
|---|---|
| `doorbell-symbol.svg` | The mark alone, dark (#1B1D19) on light backgrounds |
| `doorbell-symbol-white.svg` | The mark alone, white, on dark or coloured backgrounds |
| `doorbell-app-icon.svg` | Mark on the lime tile (#D8F29F): favicon, app icon, sidebar |

Next to the mark, "Doorbell" is set in Atkinson Hyperlegible Next Bold. Keep at least half the mark's width as clear space around it. Smallest size: 16 px.

The old logo is in `design-backup/v1/logo.svg`.
